# MyNews

**MyNews** is a personal news aggregator that automatically collects articles from the sources you follow and shows them in one place.

- **Automatic collection** – pulls articles from RSS feeds every 2 hours via GitHub Actions.
- **Daily Discord digest** – sends a summary of the latest news to Discord every day at 9:00 AM KST.
- **Simple web view** – browse articles by category on a static page hosted with GitHub Pages / Vercel.

Live demo: https://mynews-0905.vercel.app

Built with Node.js (`rss-parser`), GitHub Actions, and vanilla HTML/CSS/JS.
